TERMWISE AI / REFERENCE CODE MAP

Follow a counteroffer from click to calculation.

This app connects a contract's payment dates with a supplier's cash needs. The browser collects confirmed inputs; Python calculates exact balances and verifies candidate terms. Documents provide source evidence. Optional AI interprets clauses and never performs the financial arithmetic.

This is a reference route prepared from the implemented source, not a claim that the learner has completed an interactive code tour. Snapshot: the initial October 22, 2026 implementation; source may change after this guide.

To change this, start here

  • Cash ordering or reserve logic: backend/app/engine.py → simulate, with expected-result tests in backend/tests/test_engine.py.
  • Amount/date/currency validation: backend/app/schemas.py → Deal.check_schedule.
  • Document parsing or model response handling: backend/app/extraction.py → parse_document, rule_extract, extract.
  • Report and draft wording: backend/app/reports.py → generate_report. It uses recalculated results.
  • UI labels, layout, or colors: frontend/src/App.tsx and frontend/src/styles.css.

A practice to reuse

Define an independently checkable outcome before trusting generated code. Here, the hand-calculated supplier example needs INR 60,000 before the delivery expenses to preserve INR 20,000 cash. test_baseline_and_stress_solver checks that the returned advance is 30%; test_solver_against_independent_integer_oracle checks a wider set without copying the Decimal implementation. On another project, write one fixed expected outcome for its most consequential behavior.

How the data is kept

Inputs live in the current browser tab and backend request memory. A refresh discards the deal; report download is explicit. No server database or document store exists. If a model provider is configured, its service receives document text and has its own retention rules.

Run and revisit

Use the complete Windows/Linux/macOS setup instructions in README.md. After dependencies are installed:

cd frontend
npm ci
npm run build
cd ..
python -m uvicorn backend.app.main:app --port 8000

Open http://127.0.0.1:8000, choose the fictional supplier example, and inspect the event ledger. To test: python -m pytest -q. A safe optional edit is changing an interface label, then rebuilding and checking the visible result; do not modify calculations without a corresponding expected-result check.
